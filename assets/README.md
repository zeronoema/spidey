# Aset (disediakan sendiri)

Letakkan dua berkas milikmu sendiri di folder ini (tidak disertakan di
repo):

```
assets/mask.png    -> gambar topeng, PNG dengan alpha channel
assets/song.mp3    -> satu track lagu, ~60 detik, tanpa loop
```

`spider_filter.py` akan memeriksa keberadaan kedua berkas ini saat
dijalankan dan berhenti dengan pesan jelas kalau belum ada.
